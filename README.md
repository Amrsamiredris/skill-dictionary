# Skill Dictionary

Fast, Apple-style spotlight for AI skills.

## Features

- Fast search with category filtering
- Command palette (`Cmd/Ctrl + K`) to jump to skills
- Clean skill cards with:
  - Copy prompt
  - Copy install command
  - GitHub link
  - Copy share link
- Favorites (pin/unpin) with pinned strip
- Per-skill private notes persisted in `localStorage`
- Sorting: default, most used, recent
- Grid/list view toggle
- Share links via `#skill-id` (scroll + highlight)
- Custom skills (add/edit/delete), persisted in `localStorage`
- Dark mode + lightweight Apple-style UI

## LocalStorage

Stored under one key:

- `skill_dict_state_v2`

## Run

Open `index.html` directly in a browser.

No framework. No build step. No external JS dependencies.
