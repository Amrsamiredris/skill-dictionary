# Skill Dictionary

Operational, Apple-style “spotlight” for AI workflow skills.

## Features

- Fast searchable skill cards with copy-ready prompts
- Workflow Chains tab with strategic multi-skill sequences
- Use Before / Use After linked pills for graph navigation
- “When Not to Use” guardrails on every skill
- Expandable real examples gallery per skill
- AI tool compatibility matrix + best platform badge
- Protocols section for reusable project-start operating flows
- Smart recommendation engine for next-skill suggestions
- Local analytics (usage, workflow copies, recent, streak, sparkline)
- Universal export support (JSON, YAML, Markdown)
- All persistence in `localStorage`

## LocalStorage keys

- `sd_usage`
- `sd_recent`
- `sd_custom_skills`
- `sd_workflows`
- `sd_protocols`
- `sd_examples`
- `sd_analytics`
- `sd_recommendations`

## Run

Open `index.html` directly in browser.

No framework. No build step. No external JS dependencies.
